# 0.4.0-preview.1 readiness

Prepared on 2026-09-17 for PR review. This is a layout-comparison prerelease, not final 0.4 approval or authorization to publish downloads.

## What people can evaluate

All eleven layouts use the same editable fictional notebook. They offer different note navigation, activity tabs, evidence displays, suggestions and focus arrangements. The sketch adds recursive split panes with direct tab dragging and divider resizing. The gallery saves its selection, sample content and layouts separately from the real library. New users can enter from account setup without connecting an account; existing users enter from the library or Appearance settings.

Every layout reserves the Electron title-bar row. The sketch's selector is visible in its compact top bar; the other ten retain their comparison row. Window controls, logo, menu and input placeholders follow the gallery's own theme even when it differs from the app theme.

## Boundaries for reviewers and testers

- Gallery AI, audio, import examples and model jobs are simulated and labelled. The gallery does not exercise provider quality or real-vault behavior.
- The regular application is still available after leaving the gallery; real AI onboarding remains required. No existing library data migration was added by the gallery.
- macOS ARM64/x64 native build and smoke validation belongs to PR CI. Windows evidence is not evidence of Mac success. Mac signing remains ad-hoc and unnotarized.
- Touch/physical-controller use and learner outcomes were not evaluated in this pass.
- Publishing the prerelease requires an explicit exact-version release approval. Final 0.4 approval remains separate.
