# SenniBook 0.2.9 — 14 September 2026

This release brings together today's desktop, source, speech and reliability work.

- **Windows app:** installer and portable builds, a private local backend, background/tray operation, a cleaner top bar and a Settings sidebar back button.
- **Course material:** document, slide, image and recording imports; retained originals; local English/Dutch printed-page OCR; guided local transcription with timestamps and corrections.
- **Learning from sources:** bounded passage selection for larger course packs, inspectable citations and consulted-source disclosures, preserved episode evidence, and clearer outline validation with one bounded repair attempt.
- **Speech and listening:** Codex App Server integration; Google and Cartesia speech; separate host voices, previews and reusable audio segments; native 44.1 kHz Cartesia audio; remembered playback position, episode/chapter and speed; WAV/MP3 exports.
- **Everyday reliability:** recoverable Trash with explicit permanent deletion, preservation of shared files, draft recovery across navigation, faster library summaries, clearer import/save failures, and native streamed downloads with cancellation and visible errors.
- **Portable backups:** current sources, historical episode snapshots, originals and audio restore into a new notebook. Large backups now deduplicate repeated source sets; small backups retain v2 compatibility. v3 backups need 0.2.9 or later to restore.

Research also advanced a five-area learner preparation conversation and evaluated local speech options. Those remain research/prototypes; a required learner interview and production local TTS are not included.

Validation: 38 application tests passed, including new large-backup round-trip and malformed-snapshot regressions. Packaged desktop startup, sandbox, private-backend access, notebook persistence and restart passed, as did large-backup restore, download success/failure/cancellation and import/filter workflows. The reliability sweep used isolated libraries without new paid generation or changes to the owner's library. Earlier provider/audio trials from other workstreams are recorded separately in WORKLOG.md.

Quit an older running version before opening the installer or portable executable. Existing desktop data stays in the same application-data folder. Source, credentials and notebook data are separate: personal libraries, credentials, generated media and diagnostic artifacts are excluded from Git.
