# LMBook 0.3.4

Coordinated motion makes navigation and changes easier to follow while preserving the reading-room design.

- Selection markers travel between notebooks, sections, chapter choices and flashcard views.
- Sources open in layers; following evidence scrolls to and briefly emphasizes the exact quoted passage.
- Lists settle after filtering, importing and recovery. Dialogs and disclosures open with related content; controls acknowledge input and actual save results.
- Flashcards coordinate direction changes, question arrival, answer reveal, typed feedback and round progress. Each transition renders only the current face, preserving answer concealment during rapid navigation.
- Playback indicators respond to real playback and stop animating when paused, offscreen or hidden.
- Device reduced-motion preferences apply immediately. A local Reduce motion option is available in Connections & settings → Your library → Motion.

Existing libraries and LMBook/SenniBook upgrade compatibility are unchanged. No new motion dependency or paid generation is required.

Windows downloads: `LMBook Setup 0.3.4.exe` and `LMBook-0.3.4-portable.exe`. Quit an older running version before opening the update.
