# LMBook 0.3.16

Local Windows iteration with live TypeSafe Jev verification. No 0.4 publication approval.

- Flashcard review separates evidence from recall design, so correct cards that reveal their answers can be flagged.
- Uncertain reviews prominently say **Needs review**, with the original suggestion and probability details available.
- A provider choice that conflicts with its probability distribution cannot authorize an automatic link; search retains its original order on that inconsistency.
- Review refreshes cannot overwrite newer results or feedback.

Live authentication, multilingual synthetic judgments, the maximum supported review batch and desktop review/feedback/reload flows were evaluated using the owner's key without sending owner notes. Jev still makes semantic mistakes; checks remain advisory and never certify translations or source completeness. [Evidence and limits](../research/jev-live-evaluation.md).
