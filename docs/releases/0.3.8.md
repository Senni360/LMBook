# LMBook 0.3.8

LMBook now has macOS desktop packages for Apple Silicon and Intel, alongside the existing Windows downloads.

- Mac downloads are `LMBook-0.3.8-mac-arm64.dmg` / `.zip` for Apple Silicon and `LMBook-0.3.8-mac-x64.dmg` / `.zip` for Intel. Open the DMG and drag LMBook into Applications.
- The Mac app keeps native traffic lights and the application menu. Closing its window keeps the app available in the Dock; Command-Q quits with the existing active-work confirmation.
- Finder launches search standard Homebrew and user CLI locations. Local transcription defaults to Python 3 on Mac. Optional NVIDIA runtime installation remains Windows-only.
- Native CI builds and checks Windows, Apple Silicon and Intel packages before combining their checksums or publishing any release.

These initial Mac builds use an ad-hoc signature and are **not Apple-notarized**: no Developer ID credentials are configured. macOS may require approval in System Settings → Privacy & Security after the first launch attempt. See [Apple's opening guidance](https://support.apple.com/en-us/102445) and the [Mac setup and evaluation notes](../macos.md). Managed Macs may prohibit opening unnotarized apps.
