# LMBook 0.3.3 — a new name for your learning notebook

SenniBook is now **LMBook**.

- Updated application branding, Windows menus and tray, installer and portable executable names, exports and media attribution.
- Existing desktop libraries, provider settings, drafts and playback positions remain accessible. Existing SenniBook profiles are reused in place; fresh installations use the LMBook profile folder.
- Notebook ZIP backups and flashcard JSON retain their compatible format identifiers.
- All existing audio, flashcard, typing, language-direction and controller features remain available.

Quit the previous app before opening LMBook. Download `LMBook-Setup-0.3.3.exe` to install, or `LMBook-0.3.3-portable.exe` to run the portable edition. Updating the source or downloading a release does not replace an already running app.
