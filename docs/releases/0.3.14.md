# LMBook 0.3.14 — pre-0.4 reliability fixes

- Moving a notebook to Trash now preserves its shared-folder relationship. Restore reopens the same workspace; permanent removal disconnects the folder while preserving its files.
- Source imports stop at the supported 2,000-source limit, preventing an oversized notebook that cannot be backed up.
- Incomplete folder scans remain visible after sync instead of appearing fully successful.
- Narrow panes keep note filters, filenames and the flashcard deck selector readable.

The production build and all 38 existing application tests pass. Real Luna vocabulary generation, local E5 execution/indexing/cancellation, external-edit conflict recovery, failed flashcard-save recovery, direction switching and responsive layouts were exercised in isolated libraries. See the [audit, evidence and remaining 0.4 checks](../audits/0.4-release-readiness.md).

Windows installer and portable delivery use only `D:\Downloads\SenniBook\release\0.3.14`. This preview does not publish or approve 0.4. No paid OpenRouter request or native Mac evaluation was performed in this audit.

The packaged Windows executable passed the existing isolated startup, sandbox, persistence and restart smoke. A separate visible native run passed vault export, learning-source exclusion, Trash/startup pairing, restore to the same folder, permanent removal and original-file preservation. Its dark-mode screenshot was inspected; no renderer exceptions were observed.
