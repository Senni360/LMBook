# SenniBook 0.3.1 — editable word lists

Flashcard generation now opens one editable word list. GPT-5.6 Luna detects the two languages; each word and its supplied translation are stored once. Each pair has its own editing box, with automatic saving, optional examples and chapter labels, and inspectable source evidence. Language labels can be corrected after generation.

Practise that same list in either direction, with separate Flashcards and Type answers controls. Controller, keyboard, chapter selection, shuffle, dark surface and missed/unanswered practice remain available. Switching direction or practice mode never generates another deck. Upcoming answers remain absent from the rendered interface until revealed.

The owner explicitly chose to allow practice before source review is complete. Review status remains visible and JSON export includes it. Editing a pair clears its source review and retains the original quotation. Unsaved edits wait for a successful save before practice/export; conflicting edits and lost-response retries are handled without silently overwriting a newer pair.

Validation: production build and all 38 existing application tests passed. Browser and native Electron exercises covered inline autosave, rapid cross-row edits, both directions, strict typing, answer visibility, persisted edits and JSON export with incomplete review. Browser checks additionally exercised save-response loss/retry, draft recovery after navigation, 390px layout and a simulated standard controller. A real Luna call detected Français/English and copied four supplied pairs unchanged in 14.089 seconds. These checks do not establish educational effectiveness, physical-controller compatibility or arbitrary-PDF extraction accuracy. No additional automated test files were added.

Final Windows installer/portable executables and SHA-256 sums are available under `release/0.3.1/`. The packaged word-list workflow, native JSON download and existing startup/private-backend/sandbox/persistence/restart check passed. Packaged renderer HTML/JS/CSS, backend and download bridge match the final source build. All 148 reference pairs open in editable, searchable boxes. Editing an accepted pair clears its review, retains its original quotes and survives notebook ZIP restore.

The original idioom PDF remains unavailable. See [requirements, current flow and evaluation](../research/flashcards-plan.md). This feature branch preserves the separate interface-copy edits in the original workspace; those edits are outside the PR and this local build.
