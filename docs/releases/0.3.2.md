# SenniBook 0.3.2 — flashcard types and optional translations

Choose **Words & translations** for language learning or **Concepts & explanations** for terms selected by the agent from a text. Concept explanations can use their own wording while retaining source quotations for review. Existing failed vocabulary setups can reopen as concept creation.

**Generate missing translations** is a separate option, off by default. When enabled, only missing translations may be generated; supplied idioom translations retain priority. Generated answers are labelled as AI translations and retain that provenance in the editable list, JSON export and notebook backups. You can optionally choose their target language.

Remaining source-check problems no longer discard a usable list after an unsuccessful repair. Problems remain visible, and practice is available while review is incomplete. The same list supports both directions, typing, keyboard and controller practice; switching does not regenerate cards. Upcoming answers remain hidden until revealed.

Validation: all 38 existing application tests, production/desktop builds and the existing Electron smoke check passed. Browser and native Electron exercises covered editing, practice, answer visibility, persistence and JSON export. Additional browser checks covered the new controls, 390px layout, source warnings and backup provenance. Three real Luna runs exercised the reported history setup and missing translations off/on; two supplied translations remained unchanged in both vocabulary runs. Fault-injection diagnostics verified draft preservation and rejection of source-absent translations when disabled. No new automated test files were added.

These checks do not establish infallible PDF extraction, linguistic or semantic accuracy, physical-controller compatibility or learning effectiveness. See [the flashcard evaluation record](../research/flashcards-plan.md).
