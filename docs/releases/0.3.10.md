# LMBook 0.3.10

Fixes the clipped-looking Trash disclosure in Settings. The card now has a complete border, consistent inner spacing and an aligned disclosure arrow, icon and label. Open content shares the same inset. Plain settings disclosures no longer receive a card background and rounded corners without a corresponding container layout.

Desktop/mobile visual checks and keyboard opening passed. This patch does not add Obsidian integration; that request is in [feasibility discussion](../research/obsidian-feasibility.md).
