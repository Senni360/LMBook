# LMBook 0.3.12

- Local model setup shows current library installation and received model bytes. Network, disk-space and Python compatibility failures explain how to recover.
- Cancel waits for the installer to stop, immediately shows its stopping/cancelled state and keeps completed downloads for retry. Retrying repairs an interrupted Python environment instead of trusting the presence of python.exe alone. Progress polling no longer waits for expensive hardware/runtime checks.
- Luna's hardware advice is limited by its prompt to 45 words and one or two short sentences. The observed live reply was 19 words in approximately 5.5 seconds through the existing Codex subscription.
- Codex onboarding, OpenRouter settings and optional local meaning search from the previous preview are included.
- Desktop packages now go to the main checkout's normal `release/<version>` directory with uploading disabled.

This is a local Windows release. It does not approve 0.4 publication. See WORKLOG.md for observed installation, cancellation and packaged validation.
