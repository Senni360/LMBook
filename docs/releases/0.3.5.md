# LMBook 0.3.5

Smoother everyday editing and a focused cleanup across the application.

- Chat typing reuses saved citation locations instead of repeatedly scanning the same sources.
- Audio assembly uses less temporary memory while preserving every output byte.
- Large word lists validate more efficiently; Studio and word-list editors reuse unchanged analysis.
- Background refreshes no longer overlap or replace a newer saved edit. Generation history follows the latest refresh.
- Dead code, duplicate error handling and obsolete animation rules have been removed. Source checks, autosave recovery, both practice directions and controller support remain intact.

See [measurements and verification](../audits/app-cleanup.md) for the tested workloads and limits.

Windows downloads: `LMBook Setup 0.3.5.exe` and `LMBook-0.3.5-portable.exe`.
