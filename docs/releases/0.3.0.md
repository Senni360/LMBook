# SenniBook 0.3.0 — flashcards

Local Windows installer and portable build under `release/0.3.0/`. Quit an older instance before opening the new executable. Existing notebooks use the same desktop library. No remote release was published in this workstream.

## Added

- Flashcards section: custom instructions, explicit sources, select/deselect all and GPT-5.6 Luna through the existing Codex login. Vocabulary copies source pairs; concept cards generate questions with evidence.
- HTML word-list import compatible with the owner's supplied German deck, plus tab-separated text import. The original HTML's 148 pairs are copied without evaluating its scripts or calling a model.
- Review of original/saved sources, exact quotation checks, pair review, requested-entry count and coverage confirmation. OCR corrections can be manually transcribed with a page/row and note while retaining the original faulty extraction. Editing clears readiness.
- Single-face study: upcoming answers are not mounted or animated. Both directions, chapter selection, shuffle, typing, examples, missed/unanswered practice, keyboard controls, optional mouse grading, standard gamepad mapping and dark study surface.
- Strict typed answers preserve articles, case, accents, ß and punctuation. Position and direction-specific practice outcomes persist on the same device. Deck data, review state and historical originals survive notebook ZIP backup/restore; study-session preferences/progress remain device-local.
- Deck JSON and source-original downloads through the native desktop bridge. Trash retains shared originals referenced by flashcard snapshots.

## Verification and limits

The flashcard checkpoint passed the build and 38 existing application tests. Packaged startup/private-backend/sandbox/persistence/restart passed. Packaged flashcard import, reveal/navigation/typing, source guards, native downloads and a separate study-session restart passed without renderer errors. One real Luna call preserved four authored pairs in 9.084 seconds. Isolated correction/coverage, cancellation/interruption, backup and shared-file-purge checks passed. Desktop and 390px browser layouts were inspected; a simulated standard controller exercised reveal/next actions. No new automated test files were added.

The original idioom PDF was not supplied. Imported-list fidelity is not textbook fidelity, and matching extracted text cannot establish infallible OCR or row pairing. The UI distinguishes these limits and human transcriptions. Physical gamepad use, full-deck model generation, real scanned/multi-column vocabulary extraction and learning effectiveness remain unevaluated.
