# LMBook 0.3.13 — unified notebook workspace

- Notebooks now open as Markdown workspaces with notes, a large reader/editor and learning tools in three resizable panes. Pane widths are remembered. Open an existing Obsidian folder as a notebook, or create a notebook with its own Markdown folder.
- Saved notes become learning sources. Sync notes refreshes external changes; opening or returning to the workspace also syncs. Existing conversations and recordings retain their earlier evidence. Removing a learning source leaves its shared file intact.
- Export vault saves Markdown, attachments and readable learning material in an Obsidian-compatible ZIP. For recordings and complete LMBook restoration, use the full notebook backup.
- Appearance settings add light, dark and system modes with five accent colors. Drawn pane frames, controls and focus outlines follow the chosen palette.
- Local AI settings distinguish downloaded files, a working runtime and enabled search. Check model runs a real offline check. Search by meaning in the notebook offers indexing, progress, cancellation and a route to try the result. Downloaded models no longer look like they need downloading again.
- An interrupted setup returns to a retryable state after reopening the app. Pending OCR/transcription sources become Markdown notes after readable text is available, avoiding empty placeholder notes.

The real PWS vault was evaluated in an isolated library: 291 notes and 1,494 indexed passages, with no edits to the original files. Luna answered a separate saved-note question through Codex with the correct source quotation. OpenRouter remains available in Settings; no live paid OpenRouter request was performed for this release.
