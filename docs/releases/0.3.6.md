# LMBook 0.3.6

Ink becomes the default design, with a more human-created feel throughout the app.

- Every application button has its own subtly irregular pen contour, with a short retrace on hover or keyboard focus.
- Ink underlines replace the bookmark ribbon. Paper surfaces, small corner variations and restrained highlighting tie the interface together.
- Text, icons and reading layout stay precise. Reduced motion, autosave, keyboard input and single-face flashcard practice remain supported.

The [Ink specification and evaluation](../ui/ink.md) records the treatment and checks. Earlier style experiments remain available only in the development comparison lab.

Windows downloads: `LMBook Setup 0.3.6.exe` and `LMBook-0.3.6-portable.exe`.

The local visual refinement in `release/0.3.6-vision/` improves heading scale, supporting-text readability, word-list density, study alignment and mobile controls. It preserves the initial build in `release/0.3.6/` and has not been published as a GitHub release.
