# LMBook 0.3.7

Ink now uses one interaction system across buttons, editing fields and chat.

- Available controls draw a light contour on hover; keyboard and editing focus strengthen the same outer edge. Interrupted hover reverses smoothly.
- Chat has one writing-surface outline and stays within the available desktop height.
- Heading highlights follow section arrival consistently. Disclosure chevrons, creation pluses and value controls reflect their state.
- Removed repetitive interface slogans and simplified task labels. Source-review and recovery information remain.
- Field contours are measured near the viewport. Native editing, resizing, autosave, reduced motion and Windows forced colors remain supported.

[The research, decisions and evaluation](../ui/ink-interactions.md) include limitations and discarded approaches. This is a local build, not a published GitHub release.

Windows downloads: `LMBook Setup 0.3.7.exe` and `LMBook-0.3.7-portable.exe`.
