# LMBook 0.4.0-preview.1 — Explore your workspace

An experimental layout gallery for comparing eleven ways to use a learning notebook. This is a prerelease for feedback, not the final 0.4 release.

## Try the layouts

- On first launch, choose **Explore 11 workspace layouts** before connecting an account. Existing users can choose **Explore workspace designs** in the library sidebar or Appearance settings.
- Choose a layout with the visible numbered picker. Every layout uses the same sample notebook, so you can compare navigation, notes, chat, flashcards, audio controls and AI suggestion placement without starting over.
- The eleventh layout follows the owner's sketch: drag tabs onto pane edges or tab strips, resize dividers in either direction, and keep several views visible. Undo and reset let you experiment. Your arrangement is saved on this device.
- Light/dark mode and accent choices are available in the gallery. The Electron title bar follows the gallery's colors and no longer covers the layout picker.

## What the preview means

The gallery uses fictional notes and simulated AI, audio and model jobs. It does not call your providers, download models or change your real Obsidian vault. Edits made in the gallery remain in its separate sample library. Exiting returns to the regular app; using its real AI features still requires the normal account setup.

Try editing a note, opening its evidence, handling a suggestion and changing study direction in several layouts. Note which layout you prefer, the task you tried, and anything that got in your way when sharing feedback. Keeping the same sample content makes comparisons easier.

## Delivery and limitations

Windows installers and portable builds use the normal release folder. Native macOS checks run on the PR; Mac packages remain ad-hoc signed and unnotarized. No successful macOS check is claimed from Windows validation.

This PR prepares prerelease-aware packaging: a preview is marked **Pre-release** on GitHub and cannot replace the stable **Latest** release. The owner approved publishing this exact prerelease after PR #11 merged. The final 0.4 milestone remains unapproved.
