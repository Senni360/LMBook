# LMBook 0.3.11 — shared-vault preview

This is a local iteration toward 0.4, not an approved public release.

- Connect existing Obsidian vault folders without copying or moving them.
- Browse, search, edit and create Markdown notes in the shared folder. Recover unfinished drafts and earlier LMBook saves, compare external changes, and save a conflicting draft as a separate copy.
- Select notes for notebook questions, flashcards and audio, with preserved source snapshots.
- Generate an editable summary draft from selected notes, inspect its original inputs, and save a new vault file after review.
- Keep Obsidian configuration and plugin markup intact, with a handoff to the separately installed Obsidian app.

See [workflow, compatibility boundaries and evaluation](../obsidian-vaults.md). Arbitrary Obsidian plugins, Canvas and graph views are not embedded. Windows preview packaging is checked locally; native Mac and real-vault/sync evaluation remain part of the 0.4 iteration.
